# goodcraft (goodmod) - NeoForge 1.21.1

A port of the goodcraft mod to Minecraft 1.21.1 using NeoForge and GeckoLib.

## Requirements

- **Minecraft**: 1.21.1
- **NeoForge**: 21.1.84+
- **GeckoLib**: 4.7.4+
- **Java**: 21

## Building from Source

To compile and build the mod jar:

```bash
# Windows
.\gradlew.bat build

# Linux / macOS
./gradlew build
```

The output JAR will be placed in `build/libs/`.

## Running the Development Client

```bash
# Windows
.\gradlew.bat runClient

# Linux / macOS
./gradlew runClient
```
